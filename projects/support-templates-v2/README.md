# Бібліотека шаблонів відповідей

React + Vite. Інструмент для саппорт-команди Stripo: шаблони відповідей зі
змінними, пошуком і копіюванням у буфер.

## Запуск

```bash
npm install
npm run dev
```

Відкриється на http://localhost:5173

## Як користуватись

1. Зліва — список шаблонів. Можна фільтрувати по тегах і шукати.
2. Клік на шаблон — відкривається детальна панель.
3. Заповнюєш змінні (опціонально). Превʼю оновлюється на льоту.
4. Жмеш «Скопіювати» — текст з підставленими значеннями в буфері.

## Стек

- React 18
- Vite 5
- Fraunces / Inter Tight / JetBrains Mono
- Без зайвих залежностей
