# Стиль коду

- Plain JavaScript — без TypeScript
- React 18 functional components, без class components
- Без зайвих абстракцій — три схожі рядки краще передчасної абстракції
- Без коментарів у коді якщо WHY не очевидний
- Нові шаблони — через factory-функції де є відповідний генератор
- `id` шаблонів — kebab-case, унікальний в межах усього масиву
