# Ідеї для розширення

- Tabs з категоріями замість єдиного списку (`templateCategories` вже є в `index.js`)
- Улюблені шаблони в `localStorage` + кнопка ★
- Лічильник використання (analytics в `localStorage`)
- Keyboard shortcuts (Cmd+K для пошуку)
- Pre-fill змінних з URL (`?client_name=John&ticket_id=...`)
- Юніт-тести на `vitest` для `extractVariables` / `substituteVariables`
- Скрипт `scripts/sync-helpcenter.js` — парсить HC через cheerio, оновлює `helpArticles.js`
